# Sochi - Kyoto Ceremonial Matcha

An interactive single-screen artisan matcha experience built with Tailwind CSS, smooth responsive CSS transforms, and photorealistic 3D beverage visuals.

## Features
- **Photorealistic 3D Visuals**: Ceremonial matcha cups layered over Kyoto studio ambiance.
- **Side-to-Side Fruit Loop Carousel**: Interactive flavour switcher with 3D fruits.
- **Interactive Hero Cup**: Click directly on the center cup to view details and order.
- **Artisan Cart Modal**: Quiet luxury editorial specification modal with zero clutter.

## Quick Start
Open index.html in any modern web browser.
